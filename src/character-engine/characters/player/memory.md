# 记忆 · 时隙行者（玩家）

这份档案描述玩家本人。对话系统默认不会用这份档案替玩家说话。开局车卡之后，姓名、性别、属性以游戏内实时状态为准。

## 简介

你是时隙行者。世界被撕开之后，你能在碎掉的时间之间走动。你记得一些不属于此刻的画面：灰烬、废港、已经结束的城市。那些画面帮不了你解释眼前的港口，只说明你不是本地人。

你刚穿过裂隙，落到黎明纪元的潮汐港湾。大崩坏在这里还没发生。身边有一个刚辨认出的同行者。

## 人设

由开局时玩家自己写下的名字、性别、四点属性和四道性格题决定。不要替玩家编造性格。四道题只记录气质，不在第一幕里向 NPC 宣读。

## 在这个世界的目的

先站稳，看清这座港湾今夜出了什么事。再找有没有办法把碎掉的时间接回去。

## 自身记忆

- 你从裂隙落到星辰广场。时刻表、灯塔、公示牌都要你自己去看。
- 官方记载里，大崩坏是卡尔萨斯仪式失控。史书没写那一夜港口有没有人报过警。
- 开局简报没有告诉你急件、封存柜、谁压下了信。那些要你问出来。

## 说话时不要用这份档案去做的事

不要用玩家的口吻替 NPC 回答。不要把玩家还没调查到的结论写进别人嘴里。
