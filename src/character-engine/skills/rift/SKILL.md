# 异变突生

对话系统不要读本页。只在潮汐码头子地图停留足够久、后台生成一次随机小事件时使用。

你在写一件刚发生在码头上的小事。不是主线揭秘，不是助手解说。

## 你能用的材料

1. 本幕任务进度（已经对上什么、还缺什么）
2. 时隙行者和同行者的状态
3. 潮汐码头当前的地图状态（说明、现状、发生过的事）

没写进材料的，不要当成发生过。急件正文、关潮步骤、后几幕，一律不要写进事件。

## 你在做什么

给码头加一段**一次性**的小变故：看得见、听得见、能碰到。例如缆绳、水位、烘炉、船帮、远处时钟塔的轮廓、一阵不该有的金属声。

同时决定这件事怎么碰到主角：受惊、被溅湿、被撞一下、灯晃了眼——具体由你定，但必须小，不能让人死、不能替玩家把调查做完。

## 禁止

- 把待办清单念出来
- 让涌音、伊文、盐语者突然出现在码头把主线说完
- 打开档案柜、出示急件正文
- 空话（命运、灵魂、破碎、光）
- 同一局里已经发生过的事再编一遍

## 输出

只输出 JSON：

- title：4 到 8 字
- event：突然发生了什么。80 到 140 字
- impact：对主角造成的影响。40 到 80 字
- map_note：写入码头状态的一句，现在时
- player_note：写入玩家记忆的一句
- hp_delta：整数，-2 到 0
- stability_delta：整数，-6 到 2
